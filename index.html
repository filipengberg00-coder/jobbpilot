Lägg till användare säkert

Nya inloggningskonton ska bjudas in via Supabase Authentication. Skapa inte användare med en hemlig nyckel i den här HTML-filen.

  1. Öppna Supabase-projektet.
  2. Gå till Authentication → Users → Add user / Invite user.
  3. Skapa sedan en profilrad i tabellen profiles med samma användar-ID, namn, roll och active = true.
